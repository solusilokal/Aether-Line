# Aether Line - Sewa Busana Premium & Gaun Pesta 👗✨

Landing page & katalog digital interaktif untuk **Aether Line**, penyedia sewa gaun pesta, kebaya modern, jas pria eksklusif, dan gaun pengantin mewah.

---

## 🌟 Fitur Utama

- 📱 **Mobile-First Luxury Design**: Desain responsif bertema emas elegan (*Gold & Clean White*).
- 🖼️ **Katalog Busana Interaktif**: Galeri busana dengan fitur **Lightbox Modal** (perbesar gambar resolusi tinggi).
- 💬 **Reservasi Otomatis via WhatsApp**: Formulir booking terintegrasi langsung dengan chat admin WhatsApp beserta detail sewa & catatan.
- 🔗 **Share Modal & Clipboard**: Fitur berbagi link katalog ke WhatsApp, Facebook, X (Twitter), dan tombol salin tautan dengan fallback otomatis.
- 📍 **Informasi Lokasi & Jam Operasional**: Terhubung langsung ke navigasi Google Maps.
- 🏷️ **Daftar Harga & FAQ Interaktif**: Transparansi paket sewa dan accordion tanya-jawab yang informatif.
- ⚡ **Instant Preview**: Dilengkapi file `preview.html` mandiri yang dapat dibuka langsung di browser manapun tanpa instalasi Node.js.

---

## 🛠️ Tech Stack

- **Framework**: [React 18](https://react.dev/) + [TypeScript](https://www.typescriptlang.org/)
- **Bundler**: [Vite 5](https://vitejs.dev/)
- **Styling**: [Tailwind CSS 3](https://tailwindcss.com/)
- **Icons**: [Lucide Icons](https://lucide.dev/) & Custom SVG
- **Typography**: Playfair Display & Plus Jakarta Sans

## 🚀 Cara Menjalankan Proyek

### 1. Clone Repositori
```bash
git clone https://github.com/solusilokal/-Aether-Line.git
cd -Aether-Line
```

### 2. Instal Dependensi
```bash
npm install
```

### 3. Jalankan Development Server
```bash
npm run dev
```
Buka browser dan akses `http://localhost:5173/`.

### 4. Build untuk Produksi
```bash
npm run build
```
File hasil build akan berada di folder `dist/`.
